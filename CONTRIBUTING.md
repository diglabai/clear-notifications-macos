# Contributing

Contributions are welcome.

1. Keep the app local-only and dependency-light.
2. Never add analytics, telemetry, notification-content logging, or network access without a public design discussion.
3. Run `./Scripts/check-release.sh` before opening a pull request.
4. Describe the macOS version used for any Accessibility behavior test.

Bug reports should include reproducible steps and macOS version, but never private notification content.
