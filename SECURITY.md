# Security policy

## Supported version

The latest public beta receives security fixes.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not place secrets, private notification content, credentials, or personal data in a public issue.

## Distribution boundary

Only downloads attached to this repository's GitHub Releases are official. A downloadable app will not be presented as trusted until it is Developer ID signed, hardened, timestamped, notarized, stapled, and verified with Gatekeeper on a clean Mac.
